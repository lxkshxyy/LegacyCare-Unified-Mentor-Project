# LegacyCare – Client

React 19 + Vite + Tailwind CSS v4 frontend for LegacyCare.

```bash
npm install
npm run dev     # http://localhost:5173 (proxies /api to http://localhost:5000)
npm run build   # production build in dist/
```

See the [main README](../README.md) for full setup, demo accounts and deployment.
